# MVP Backlog (Pri-1 / Pri-2) - Detailed\n\nThis document outlines the MVP backlog prioritized into Pri-1 (high priority) and Pri-2 (next priority).\n\n## Pri-1 (High Priority)\n- Local Story Library: Ensure offline access to a local vault of stories; implement reliable local persistence (IndexedDB/LocalStorage fallback).\n- Story Craftsman: Basic guided story builder with 4 steps (Hero, Place, Event, Ending); validation ensures selections complete.\n- Reader basics: Word-by-word highlighting toggle (manual/auto), Play/Pause, adjustable speed and font size.\n- Parental Gate: Implement a basic parental gate for sensitive actions (purchases/settings), display privacy policy link.\n- Profiles: Create/edit child profiles, assign age ranges, persist locally; allow switching between profiles.\n- Settings: Language selection, theme toggle (light/dark), narration volume, offline/online mode indicator.\n- Data security: Local data encryption note and COPPA alignment shout-out.\n\n## Pri-2 (Next Priorities)\n- Online Story Sourcing: Hybrid generation path (local + Gemini fallback) with graceful degradation when offline.\n- Premium Narration: Wire TTS (ElevenLabs/OpenAI) with mock fallback for testing; hook up actual API keys.\n- RevenueCat integration: Real purchase flow for subscriptions, with sandbox/testing notes.\n- Accessibility: Keyboard navigation, screen reader friendly labels, larger tap targets.\n- Localization: Full EN/TR localization for core screens and prompts.\n- Analytics & Telemetry: Basic usage analytics for onboarding, engagement while respecting privacy.\n- App Store / Play Store readiness: Ensure store metadata aligns with backlog and current features.
