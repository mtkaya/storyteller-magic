# MVP Backlog (Pri-1 / Pri-2) - Detailed\n\nThis document outlines the MVP backlog prioritized into Pri-1 (high priority) and Pri-2 (next priority).\n\n## Pri-1 (High Priority)\n- Local Story Library: Access and read stories from local vault; ensure offline support.\n- Story Craftsman: Basic guided story creation flow (4 steps: Hero, Place, Event, Ending) with simple validation.\n- Reader: Word-by-word highlight, basic play/pause for TTS, adjustable speed and font size.\n- Parental Gate & Privacy: Basic parental controls and privacy policy access; COPPA compliance notes.\n- Profile management: Create/edit child profiles, assign age ranges, store locally.\n- Settings: Language selection, theme (light/dark), volume control for narration, and offline mode indicator.\n- Basic UI/UX consistency: Ensure visual identity aligns with visuals guidelines (docs/visual-style.md).\n- Local data persistence: Ensure data is stored offline reliably (indexedDB/LocalStorage fallback).\n\n## Pri-2 (Next Priorities)\n- Online Story Sourcing: Hybrid generation path (local + Gemini fallback) with graceful degradation when offline.\n- Premium Narration: Wire TTS (ElevenLabs/OpenAI) with mock fallback for testing; hook up actual API keys.\n- RevenueCat integration: Real purchase flow for subscriptions, with sandbox/testing notes.\n- Accessibility: Keyboard navigation, screen reader friendly labels, larger tap targets.\n- Localization: Full EN/TR localization for core screens and prompts.\n- Analytics & Telemetry: Basic usage analytics for onboarding, engagement while respecting privacy.\n- App Store / Play Store readiness: Ensure store metadata aligns with backlog and current features.
