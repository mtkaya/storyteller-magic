# Seed-Level Illustration Prompt Packs

Her hikaye seed'i için hazır cover + 8 sahne + 3 branch prompt paketi.

**Global style lock** (her prompt'a ekle):
```text
children's book illustration, hand-painted digital art, soft painterly shapes, bedtime-friendly mood, whimsical but calm, no photorealism, no text, no logo, no watermark, vertical 3:4
```

**Continuity lock** (aynı hikayenin sahnelerinde kullan):
```text
same character design as cover, same costume palette, same world art direction, same brush language, no style drift
```

## Usage Tips

1. Her prompt'a **global style lock** ve **continuity lock** ekle (dosyanın başına bak).
2. Aynı hikayenin sahnelerini üretirken **tek oturumda** üret — stil tutarsızlığını azaltır.
3. Technique auto-mapping: Adventure/Courage → `gouache`, Friendship/Nature/Calm → `watercolor`, Magic/Mystery → `cut-paper`, Space/Wonder/Wisdom → `flat-storybook`
4. Ratio her zaman `3:4` dikey kullan.
5. **Negative prompt**: `no photorealism, no realistic camera, no text, no watermark, no logo, no violence, no horror`
